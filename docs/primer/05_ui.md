## 9. UI

### As-is `[DESIGN]`

No screen was built and no mockup exists. The interaction model was decided in prose, for an Expo/Android app:

- **The carousel is the container.** A primer is a horizontal, swipeable carousel of cards in the fixed order of Appendix A §4. It grows over time: chip taps append cards, they don't regenerate the primer.
- **Card 0 is the brain dump**, user-authored before the request, never edited by the app.
- **Topic in → menu of 3–5 tappable coverage options** with topic-adapted labels, plus "just the basics." No familiarity question, no purpose question, no length picker — the selection count sets depth and the UI shows the resulting read time.
- **Expansion chips** on the Curious-mode Overview (and on mini-primers), phrased as sub-topics. Tapping appends a mini-primer at its cousin's slot; the Debates chip generates the real Debates card.
- **Check Yourself** is collapsible/skippable; whether answers reveal on tap or are never shown was left open (spec §7.3).
- **Further Reading** is a list with a one-line "why this source" per entry — never bare links.
- **Cards stream in** one at a time (implied by per-card generation).
- Text-only for now; visual enrichment (diagrams for How It Works first) deferred until the loop is proven.

Because it was designed for a phone, **nothing in Primer's UI assumes a desktop**: no hover states, no wide layouts, no drag-and-drop.

### Proposed screens and flows for Text Wall `[PROPOSED]`

Four states inside the Research segment. All are plain HTML/JS; styling inherits Text Wall's tokens (the skeleton below uses CSS custom properties with fallbacks so Text Wall's palette and type win when present).

**1. Research list** — entry point. Each row: topic, depth mode, status pill, date. Tapping opens the carousel. Empty state copy: "No primers yet. Name a topic and get oriented in a minute." Primary action: "New primer."

**2. New primer** — two fields. Topic (single line, required). Brain dump (textarea, optional; placeholder: "What you think you know, and what you're trying to figure out. The primer uses this to skip what you know and correct what's off."). One button: "Get options." On tap: insert `primers` row → call `primer-menu` → go to state 3. While waiting: the button reads "Reading your topic…" and is disabled.

**3. Coverage menu** — the options from `primers.menu.coverage_options` as toggle chips, each with its topic-adapted label. Below them a live line driven by the selection count: "Just the basics · ~1 min read" (0) / "1 selected · 3–4 min read" / "3 selected · 5+ min read." Debates & Misconceptions and Further Reading are not shown as options; a footnote says "Every primer with selections includes what's debated and further reading." Button: "Build primer." On tap: compute mode, update the primer, insert card rows, go to state 4 and start the pipeline.

**4. Primer carousel** — horizontal scroll-snap strip. Cards in canonical order: virtual Card 0 (brain dump) if present, then one card per `primer_cards` row. Each card has an **eyebrow** showing its slot label ("The story", "How it works", "What's debated"…) — the fixed order is the format promise, so the label is structural, not decorative. Pending cards render as skeletons with the eyebrow already in place (the user sees the table of contents before content arrives). Error cards show the message and a "Try again" button. Card bodies render per type (see `renderCard`). Chips render as a row of tappable buttons under the Overview and under mini-primers; tapping one inserts the new card at its slot and scrolls to it once ready. Check Yourself uses native `<details>` so the answer reveals on tap. Further Reading entries link out in a new tab when a URL exists.

**Text Wall capture hook** (not in the skeleton — it lives wherever Text Wall's capture classifier runs): a capture classified `kind='research'` should call `createPrimer(topicLine, restOfCapture)` with the first line as the topic and any remaining text as the brain dump, and store the new primer's id back on the message if a link column exists. The classifier prompt needs a definition for the new kind: *a request to get oriented on a topic — "primer on X", "what's the deal with X", "explain X to me", "I need to understand X before Thursday."*

**Mobile notes for the proposed UI:** the carousel is touch-native (CSS scroll-snap; no JS gesture handling); every chip and button is ≥44 px tall; cards scroll vertically inside themselves when long; the brain-dump textarea grows with content; the "Build primer" button is sticky at the bottom of the menu state. The only desktop-only conveniences are the prev/next arrow buttons and ←/→ key handling, which are harmless on mobile. There is no hover, no drag-and-drop, no multi-column layout.

### `research.js` `[PROPOSED]`

```js
// research.js — Text Wall Research segment (Primer).  [PROPOSED — parses; never loaded in a browser]
// Reuse Text Wall's existing supabase-js client if it exposes one; otherwise create one.
import { createClient } from "https://esm.sh/@supabase/supabase-js@2";
const supabase = window.supabaseClient ?? createClient(window.SUPABASE_URL, window.SUPABASE_ANON_KEY);

// ---- constants (mirror the spec's fixed order) --------------------------------------------
const SLOT = { overview: 1, story: 2, how_it_works: 3, timeline: 4, key_players: 5, key_numbers: 6, debates: 7, check_yourself: 8, further_reading: 9 };
const SLOT_LABEL = { overview: "Overview", story: "The story", how_it_works: "How it works", timeline: "Timeline", key_players: "Key players & terms",
  key_numbers: "Key numbers", debates: "What people get wrong & what's debated", check_yourself: "Check yourself", further_reading: "Further reading", mini_primer: "More on this" };
const READTIME = { curious: "~1 min read", conversation: "3–4 min read", research: "5+ min read" };
const depthFor = (n) => (n === 0 ? "curious" : n <= 2 ? "conversation" : "research");

// ---- state ---------------------------------------------------------------------------------
const state = { primer: null, cards: [], selections: new Set() };
const $ = (id) => document.getElementById(id);
const esc = (s) => String(s ?? "").replace(/[&<>"']/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" }[c]));
const ital = (s) => esc(s).replace(/\*([^*]+)\*/g, "<em>$1</em>"); // the only markdown the prompts allow

function show(view) {
  for (const id of ["r-list", "r-newform", "r-menu", "r-primer"]) $(id).hidden = id !== view;
}

// ---- state 1: list ------------------------------------------------------------------------
async function loadList() {
  const { data, error } = await supabase.from("primers").select("id, topic, depth_mode, status, created_at").order("created_at", { ascending: false });
  if (error) return alert(`Couldn't load primers: ${error.message}`);
  const ul = $("r-list-items");
  ul.innerHTML = "";
  $("r-list-empty").hidden = data.length > 0;
  for (const p of data) {
    const li = document.createElement("li");
    li.innerHTML = `<span>${esc(p.topic)}</span><span class="pill">${esc(p.depth_mode)} · ${esc(p.status)}</span>`;
    li.onclick = () => openPrimer(p.id);
    ul.appendChild(li);
  }
  show("r-list");
}

// ---- state 2: new primer → menu call --------------------------------------------------------
async function createPrimer(topic, brainDump) {
  const { data: primer, error } = await supabase.from("primers")
    .insert({ topic, brain_dump: brainDump || null, status: "new" }).select("*").single(); // owner defaults to auth.uid()
  if (error) throw new Error(error.message);
  const { data, error: fnErr } = await supabase.functions.invoke("primer-menu", { body: { primer_id: primer.id } });
  if (fnErr) throw new Error(fnErr.message ?? "menu call failed");
  primer.menu = data.menu;
  primer.status = "menu_ready";
  return primer;
}

// ---- state 3: coverage menu -----------------------------------------------------------------
function renderMenu(primer) {
  state.primer = primer;
  state.selections = new Set();
  $("r-menu-topic").textContent = primer.topic;
  const wrap = $("r-menu-chips");
  wrap.innerHTML = "";
  for (const opt of primer.menu.coverage_options) {
    const b = document.createElement("button");
    b.className = "chip"; b.type = "button"; b.textContent = opt.label; b.dataset.type = opt.card_type;
    b.setAttribute("aria-pressed", "false");
    b.onclick = () => {
      const on = b.getAttribute("aria-pressed") !== "true";
      b.setAttribute("aria-pressed", String(on));
      on ? state.selections.add(opt.card_type) : state.selections.delete(opt.card_type);
      updateReadtime();
    };
    wrap.appendChild(b);
  }
  updateReadtime();
  show("r-menu");
}

function updateReadtime() {
  const n = state.selections.size;
  const mode = depthFor(n);
  $("r-readtime").textContent = n === 0 ? `Just the basics · ${READTIME[mode]}` : `${n} selected · ${READTIME[mode]}`;
}

// ---- build: insert card rows, run the pipeline ---------------------------------------------
async function buildPrimer(primer, selections) {
  const mode = depthFor(selections.length);
  const labelFor = (t) => primer.menu.coverage_options.find((o) => o.card_type === t)?.label ?? SLOT_LABEL[t];
  const types = ["overview", ...selections];
  if (selections.length > 0) types.push("debates", "further_reading");
  if (mode === "research") types.push("check_yourself"); // Conversation-mode toggle: deferred (see §12)

  const { error: updErr } = await supabase.from("primers").update({ selections, depth_mode: mode, status: "generating" }).eq("id", primer.id);
  if (updErr) throw new Error(updErr.message);

  const rows = types.map((t) => ({ primer_id: primer.id, card_type: t, position: SLOT[t], label: labelFor(t), status: "pending" }));
  const { data: cards, error } = await supabase.from("primer_cards").insert(rows).select("*");
  if (error) throw new Error(error.message);

  primer.depth_mode = mode; primer.selections = selections; primer.status = "generating";
  state.primer = primer; state.cards = cards;
  renderCarousel();
  show("r-primer");
  await runPipeline();
}

async function runPipeline() {
  const byType = (t) => state.cards.find((c) => c.card_type === t && c.status !== "ready");
  const ov = byType("overview");
  if (ov) await generate(ov.id);                       // 1. Overview first — everything else builds on it
  const middle = state.cards.filter((c) => !["overview", "further_reading", "check_yourself"].includes(c.card_type) && c.status !== "ready");
  await pool(middle.map((c) => () => generate(c.id)), 2); // 2. selected cards + debates, two at a time
  const fr = byType("further_reading"); if (fr) await generate(fr.id); // 3. needs Debates' sources
  const cy = byType("check_yourself"); if (cy) await generate(cy.id); // 4. needs every card
  const { data } = await supabase.from("primers").select("status").eq("id", state.primer.id).single();
  if (data) state.primer.status = data.status;
}

async function pool(tasks, size) {
  const queue = [...tasks];
  const workers = Array.from({ length: size }, async () => { while (queue.length) await queue.shift()(); });
  await Promise.all(workers);
}

async function generate(cardId, force = false) {
  patchCard(cardId, { status: "generating", error: null });
  const { data, error } = await supabase.functions.invoke("primer-card", { body: { card_id: cardId, force } });
  if (error || data?.error) {
    patchCard(cardId, { status: "error", error: error?.message ?? data?.error ?? "Generation failed" });
    return;
  }
  patchCard(cardId, data.card);
}

function patchCard(cardId, patch) {
  const i = state.cards.findIndex((c) => c.id === cardId);
  if (i < 0) return;
  state.cards[i] = { ...state.cards[i], ...patch };
  renderCarousel();
}

// ---- open an existing primer -----------------------------------------------------------------
async function openPrimer(id) {
  const [{ data: primer }, { data: cards }] = await Promise.all([
    supabase.from("primers").select("*").eq("id", id).single(),
    supabase.from("primer_cards").select("*").eq("primer_id", id).order("position").order("created_at"),
  ]);
  if (!primer) return;
  state.primer = primer; state.cards = cards ?? [];
  if (primer.status === "menu_ready") return renderMenu(primer);
  renderCarousel();
  show("r-primer");
  if (state.cards.some((c) => c.status === "pending" || c.status === "error")) {
    // Resume: retry anything pending; errors wait for a tap on "Try again".
    for (const c of state.cards.filter((c) => c.status === "pending")) await generate(c.id);
  }
}

// ---- chips → mini-primer or the real Debates card ------------------------------------------
async function tapChip(card, chip) {
  const isDebates = chip.card_type_hint === "debates";
  if (isDebates && state.cards.some((c) => c.card_type === "debates")) return scrollToCard(state.cards.find((c) => c.card_type === "debates").id);
  const row = isDebates
    ? { primer_id: state.primer.id, card_type: "debates", position: SLOT.debates, label: SLOT_LABEL.debates, status: "pending" }
    : { primer_id: state.primer.id, card_type: "mini_primer", position: SLOT[chip.card_type_hint] ?? 9, label: chip.text,
        chip_text: chip.text, parent_card_id: card.id, status: "pending" };
  const { data: created, error } = await supabase.from("primer_cards").insert(row).select("*").single();
  if (error) return alert(`Couldn't add that card: ${error.message}`);
  state.cards.push(created);
  state.cards.sort((a, b) => a.position - b.position || a.created_at.localeCompare(b.created_at));
  renderCarousel();
  await generate(created.id);
  scrollToCard(created.id);
}

function scrollToCard(cardId) {
  document.querySelector(`[data-card-id="${cardId}"]`)?.scrollIntoView({ behavior: "smooth", inline: "center", block: "nearest" });
}

// ---- rendering ---------------------------------------------------------------------------------
function renderCarousel() {
  const p = state.primer;
  $("r-primer-topic").textContent = p.topic;
  const wrap = $("r-carousel");
  wrap.innerHTML = "";
  if (p.brain_dump) {
    wrap.insertAdjacentHTML("beforeend", `<article class="card" data-card-id="brain-dump"><div class="eyebrow">Your notes</div><p>${esc(p.brain_dump).replace(/\n/g, "<br>")}</p></article>`);
  }
  const ordered = [...state.cards].sort((a, b) => a.position - b.position || a.created_at.localeCompare(b.created_at));
  for (const c of ordered) wrap.insertAdjacentHTML("beforeend", renderCard(c));
  wrap.querySelectorAll("[data-chip]").forEach((b) => {
    b.onclick = () => {
      const card = state.cards.find((c) => c.id === b.dataset.cardId);
      tapChip(card, card.chips[Number(b.dataset.chip)]);
    };
  });
  wrap.querySelectorAll("[data-retry]").forEach((b) => (b.onclick = () => generate(b.dataset.retry, true)));
}

function renderCard(c) {
  const eyebrow = `<div class="eyebrow">${esc(c.label && c.card_type !== "mini_primer" ? c.label : c.card_type === "mini_primer" ? `More on: ${c.chip_text}` : SLOT_LABEL[c.card_type])}</div>`;
  if (c.status === "pending" || c.status === "generating") {
    return `<article class="card" data-card-id="${c.id}">${eyebrow}<div class="skeleton" style="width:90%"></div><div class="skeleton" style="width:75%"></div><div class="skeleton" style="width:82%"></div><p class="muted">${c.status === "generating" ? "Writing…" : "Waiting…"}</p></article>`;
  }
  if (c.status === "error") {
    return `<article class="card error" data-card-id="${c.id}">${eyebrow}<p>This card didn't generate: ${esc(c.error)}</p><p><button class="btn secondary" data-retry="${c.id}">Try again</button></p></article>`;
  }
  const b = c.body ?? {};
  let html = "";
  switch (c.card_type) {
    case "overview":
    case "mini_primer":
      html = `<p>${ital(b.answer)}</p><p>${ital(b.map ?? b.micro_map)}</p>`;
      break;
    case "story":
      html = (b.paragraphs ?? []).map((p) => `<p>${ital(p)}</p>`).join("");
      break;
    case "how_it_works":
      html = `<p><strong>${ital(b.core)}</strong></p><ol>${(b.chain ?? []).map((s) => `<li>${ital(s)}</li>`).join("")}</ol>` +
             (b.analogy ? `<p class="muted">${ital(b.analogy)}</p>` : "") + `<p><em>What limits it:</em> ${ital(b.constraint)}</p>`;
      break;
    case "timeline":
      html = `<ul>${(b.entries ?? []).map((e) => `<li><strong>${esc(e.when)}</strong> — ${ital(e.event)} <span class="muted">${ital(e.why_it_mattered)}</span></li>`).join("")}</ul>`;
      break;
    case "key_players":
      html = (b.players?.length ? `<p><strong>Players</strong></p><ul>${b.players.map((p) => `<li><strong>${esc(p.name)}</strong> — ${ital(p.identification)} <span class="muted">${ital(p.why_they_matter)}</span></li>`).join("")}</ul>` : "") +
             (b.terms?.length ? `<p><strong>Terms</strong></p><ul>${b.terms.map((t) => `<li><strong>${esc(t.term)}</strong> — ${ital(t.definition)}</li>`).join("")}</ul>` : "");
      break;
    case "key_numbers":
      html = `<ul>${(b.numbers ?? []).map((n) => `<li><strong>${esc(n.figure)}</strong> — ${ital(n.measures)} <span class="muted">${ital(n.context)}${n.as_of ? ` (as of ${esc(n.as_of)})` : ""}</span></li>`).join("")}</ul>`;
      break;
    case "debates":
      html = `<p><strong>What people get wrong</strong></p><ul>${(b.misconceptions ?? []).map((m) => `<li>${m.from_brain_dump ? "<em>From your notes:</em> " : ""}<strong>${ital(m.belief)}</strong> — ${ital(m.correction)} <span class="muted">${ital(m.reason)}</span></li>`).join("")}</ul>` +
             `<p><strong>What's genuinely debated</strong></p><ul>${(b.debates ?? []).map((d) => `<li><strong>${ital(d.question)}</strong><br>${ital(d.side_a?.position)} <span class="muted">(${ital(d.side_a?.holders)} — ${ital(d.side_a?.source)})</span><br>${ital(d.side_b?.position)} <span class="muted">(${ital(d.side_b?.holders)} — ${ital(d.side_b?.source)})</span><br><em>Turns on:</em> ${ital(d.crux)}</li>`).join("")}</ul>`;
      break;
    case "check_yourself":
      html = (b.questions ?? []).map((q) => `<details><summary>${ital(q.question)}</summary><p>${ital(q.answer)}</p><p class="muted">Re-read: ${esc(SLOT_LABEL[q.reread] ?? q.reread)}</p></details>`).join("");
      break;
    case "further_reading":
      html = `<ul>${(b.sources ?? []).map((s) => `<li>${s.url ? `<a href="${esc(s.url)}" target="_blank" rel="noopener">${ital(s.title)}</a>` : `<strong>${ital(s.title)}</strong>`} <span class="muted">(${esc(s.creator)})</span><br>${ital(s.angle)}</li>`).join("")}</ul>`;
      break;
  }
  const chips = (c.chips?.length ? `<div class="chips">${c.chips.map((ch, i) => `<button class="chip" type="button" data-chip="${i}" data-card-id="${c.id}">${esc(ch.text)}</button>`).join("")}</div>` : "");
  return `<article class="card" data-card-id="${c.id}">${eyebrow}${html}${chips}</article>`;
}
```

**Notes on the skeleton:** it deliberately does no realtime subscription — each `primer-card` call returns the finished card, and `openPrimer` resumes any `pending` rows, which covers a closed tab. `ital()` is the only markdown rendering, matching the prompts' "no markdown except *italics*" rule; everything else is escaped. The `brain-dump` card is virtual (rendered from `primers.brain_dump`). Replace the `alert()` calls with Text Wall's own error surface.
